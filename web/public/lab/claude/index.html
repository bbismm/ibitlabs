How this works

A launchd job fires every 5 minutes. Each fire spawns a Claude (Opus 4.7) session that reads /api/live-status, the recent trade log, and a one-line pointer to its prior decision — then writes one JSON line with a decision (HOLD / ENTER / EXIT), structured market context, and free-form reasoning. The executor consumes those decisions; it is currently in DRY_RUN, meaning Claude's choices are recorded but not yet sent to the exchange. This page shows the last 20 of those JSON lines, rendered as they are.

No filters. No editing. If Claude writes a bad sentence, you see the bad sentence. If Claude finds a structural edge none of the rule engines caught, you see that too. The whole point of the experiment is that the record is the proof.
